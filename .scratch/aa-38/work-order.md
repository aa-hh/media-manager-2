# AA-38 work order: Connect Sonarr, Radarr, rTorrent and Plex through saved settings

### Goal

Give server code one way to reach Sonarr, Radarr, rTorrent and Plex using URLs and credentials saved in the existing `settings` table, so later tickets (AA-30 to AA-34, AA-40) can build on four small modules instead of each inventing its own connection. Credentials stay in the database and in request headers only: never in a URL, a thrown error, a status result, a log line, or anything a browser could see. Because no settings screen exists yet, a command-line tool lets the owner save settings on the Whatbox slot and run `connections check` there; that live run is the acceptance evidence for AA-38. Test fixtures prove only controlled behaviour.
